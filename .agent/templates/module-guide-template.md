# 模块指南模板

创建新模块指南时执行：

```sh
cp docs/_templates/module-guide.md docs/modules/<module>.md
```

随后替换所有尖括号占位内容，并在 `docs/_meta/modules.json` 登记源码路径、指南和验收命令。

## 填写要求

- “当前状态”必须逐项区分已实现和计划能力。
- “最小示例”应该是完成目标所需的最短路径，而不是完整 API 罗列。
- “验收”必须由非专业用户独立执行，并给出预期结果。
- “常见问题”写可见现象、原因和恢复动作。
- “兼容与升级”说明模型、数据、配置和协议影响；没有影响也要明确写出。

模板文件不会进入文档站导航，但会保留在仓库中供复制使用。
